添加代码仓库

先登记仓库、分支和精确 Commit，后续覆盖率任务会使用这些引用。

同一个仓库可以登记多个分支；覆盖率任务创建时会再次锁定实际 head commit。

创建测试任务

选择本轮测试关联的仓库、分支和覆盖率统计口径。

Diff 任务必须填写 base 和 head；实际执行前仍需由 Git Provider 校验 Commit 是否存在。
